# Tech Stack

This project utilizes a minimal, highly performant technology stack suitable for static single-page applications.

- **HTML5**: Semantic markup for the application structure and accessibility.
- **Vanilla JavaScript (ES6+)**: Handles DOM manipulation, event listening, and form state without the overhead of external libraries.
- **Tailwind CSS (via CDN)**: A utility-first CSS framework for rapid, consistent UI styling directly in the markup.
- **Fetch API**: Modern browser API used to construct and send asynchronous HTTP POST requests to the n8n backend.
